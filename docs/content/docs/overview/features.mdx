# Features

## Canvas projects

- Create, rename, duplicate, delete, import, and export canvas projects.
- Persist projects in the browser and optionally synchronize them with WebDAV.
- Keep viewport, background, nodes, connections, and assistant sessions with each project.

## Infinite canvas

- Pan, zoom, reset the view, select multiple nodes, copy and paste, undo and redo.
- Drag files onto the canvas and use lines, dots, or a blank background.
- Export the entire canvas or selected elements with their resources.
- Use Light, Dark, and Dark gray canvas themes. Dark gray uses a `#0a0a0a` canvas with `#464646` dots and remembers the previously selected dark theme when switching through Light.
- Create nodes from the vertical left rail and its hover menu, while canvas tools, history, appearance, delete, and clear actions remain in the bottom toolbar.
- Keep node prompt panels, creation menus, and connection menus at a stable screen size while zooming; media previews fill their rounded frames, and empty media nodes show centered icons.
- Follow the active theme in configuration-panel borders and dividers, and use a neutral `#7a7a7a` selection stroke across nodes, reference highlights, group drop targets, prompt references, and marquee selection.
- Keep image generation counts as `1 / 2 / 4 / custom`, remember the latest model and parameters independently for each node type, and show an icon-only stop control while generating.
- Limit canvas zoom to a minimum of `25%`, use a dotted grid for new canvases, and preserve each canvas's saved grid style when reopened.
- Use `236px` as the default short edge for image and video nodes, keep text nodes at `236px` high, and default image/video ratio settings to automatic while preserving node center when ratios change.
- Gracefully fall back to thread-summary reads when the local Codex app-server rejects paginated `thread/read(includeTurns=true)` requests.
- Use a `228px` node creation menu and label panorama nodes as `360°全景查看器`; keep prompt panels at `638px × 258px` with 16px corners, and keep node frames at 20px at 100% zoom.
- Provide canvas/project actions through the left toolbar with unified tooltips.

## Nodes and workflows

- Text, image, video, and generation-configuration nodes.
- Connect text prompts and reference media to generation nodes.
- Generate or rewrite text, create images, edit images from references, and create videos.
- Preserve original image ratios by default and organize batch results as connected nodes.
- Expand multi-image or multi-text batches two cards per row, with the primary card on the last row so the prompt panel stays visible.
- Hide the on-image download chip while an image is collapsed; after expanding, show icon-only overlay chips at 80% opacity, with a 50% wider count chip.
- Record prompts, models, dimensions, quality, and references on generated nodes for retries.

## AI generation

- Connect to user-provided OpenAI-compatible endpoints directly from the browser.
- Configure multiple channels, fetch or enter model names, and choose default text, image, and video models.
- Support image count, aspect ratio, quality, transparent backgrounds, reasoning effort, and custom invocation scripts.
- Support OpenAI-style video endpoints.
- Keep image and video nodes at the current-ratio default size during and after generation (`236px × 236px` for images, `420px × 236px` for videos; chosen ratios keep a `236px` short edge) instead of shrinking to the media's native pixels.

## Canvas Agent

- Connect local Codex through Canvas Agent and MCP without giving a web server direct access to browser state.
- Read the active canvas, selection, nodes, edges, generation status, and apply structured operations.
- Use Codex from the browser side panel with streaming responses, history, approvals, permissions, diagnostics, and local Skills.
- Isolate active canvases and turns across multiple browser tabs.

See [Codex App Plugin](/docs/overview/codex-app-plugin) for installation and usage.

## Plugin system

Canvas plugins can contribute node types, rendering, inspectors, serialization, migration, toolbar actions, and optional AI generation capabilities. Built-in and local plugins are managed through the canvas UI.

## Prompts and assets

- Use seven built-in prompt sources from the [Image Prompts](https://github.com/yukkcat/image-prompts) registry, with independent enablement, manual refresh, and scheduled refresh.
- Add, edit, and remove custom standard JSON sources while retaining the last successful cache when refresh fails.
- Search across enabled sources, filter by tags, inspect prompt details, copy prompts, and insert them into the canvas.
- Store reusable images, videos, audio, and prompt assets in the browser.

See [Third-party Prompt Sources](/docs/overview/third-party-prompt-repositories) for the complete built-in list.

## Configuration and synchronization

- Export and import channel, model, generation, prompt-source, local-proxy, and WebDAV settings.
- Store application data and API credentials locally in the browser.
- Use WebDAV for optional cross-device synchronization. WebDAV and remote media downloads go direct first and fall back to the local proxy on CORS, network failure, or non-media responses.
- Provide a Local proxy tab between Providers and Preferences, on by default, with `npx @basketikun/canvas-proxy@latest` and `http://127.0.0.1:23210`. The Windows launcher starts this proxy automatically.
- Keep model-list and generation requests browser-direct, except `image.52token.org`, which uses the local proxy when it is enabled. This is not a project backend proxy.

## Current limitations

- The project is frontend-first and does not provide built-in cloud accounts or cloud storage.
- API keys remain in browser storage and requests are sent directly to configured providers.
- Production Docker static-resource paths still require broader deployment verification.
